# Security Policy

## Supported Versions

Because this repository is still in the pre-release stage, old versions will not be supported after a new release comes out.

| Version | Supported          |
| ------- | ------------------ |
| 0.2.0   | :white_check_mark: |
| 0.1.0   | :x:                |



## Security & Vulnerability Reporting

If you discover a potential security issue, please report it privately to:

**gg2nq9djjb@privaterelay.appleid.com**

### What to Expect

* **No Guaranteed Replies:** Reports are monitored, but due to limited project bandwidth, you may not receive an individual reply or status update.
* **Resolution:** Valid reports will be investigated and addressed in a future update as time permits.

Please do not open public issues or share vulnerability details publicly.
